# החזרת העיצוב המקורי של Chatwoot

בקשת המשתמש: להסיר את העיצוב החדש, להשאיר את הפיצ׳רים המותאמים ולשלב אותם בעיצוב המקורי. תיקוני שימושיות מוכחים נשמרים.

## השינויים

- הוסרה ערכת `whatsapp-theme.js`: צבעי WhatsApp, טפט, זנבות לבועות, אווטארים מוגדלים, צ׳יפים, שינוי תיבת הכתיבה, מפרידי יום ושכתוב חותמות זמן. הגדרת דפדפן ישנה אינה יכולה להפעיל אותה מחדש.
- תצוגות התבניות בתוספי React משתמשות בכרטיס המקורי של Chatwoot. בוטל הרקע המנוקד בעורך הפלואו; כפתור ההפעלה ותפריטו משתמשים ברכיבים המקוריים.
- חלון הקמפיין מציג את שם התבנית, השפה והקטגוריה המקוריים. משתני Liquid, תצוגה מקדימה והעלאת מדיה נשמרים. כותרת וגוף מטופלים בנפרד.
- צבעי התוספים ומפת הצבעים הושוו למקור Chatwoot 4.17: 274 הצהרות צבע תואמות. כל מחלקות ה־CSS החדשות שמוזרקות קיימות בנכסי הליבה הפעילים.

## מה נשמר

כל טלאי הליבה 1–20, לרבות לא־נקראו, קבוצות, תיקיות, בוטים, סטודיו תבניות, ניהול WAHA, דחיסת וידאו, עברית ותיקוני נגישות, חלונות ושמירה. רצפים, פלואו, ייבוא חכם, קמפיינים ואנליטיקה נשמרים.

מתוך הערכה שהוסרה נשמרו רק שלושה תיקוני CSS מוגבלים ב־`native-ui-fixes.js`: כיוון זמני אודיו ב־RTL, בידוד שם קובץ מעורב, ומרווח גלילה כשכפתור התפריט המקורי במובייל עלול לכסות את השיחה האחרונה.

אייקון הווידג׳ט הציבורי באתר והניסוח ביחיד נשארו: אלה התאמות נפרדות שהוזמנו בעבר, מחוץ לעיצוב הדשבורד. תצוגת הטלפון המכוונת בסטודיו הליבה נשארת כתצוגה של ההודעה ללקוח.
